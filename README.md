# Prisma

A custom Minecraft launcher based on [PrismLauncher](https://github.com/PrismLauncher/PrismLauncher), with support for both **online (Microsoft)** and **offline** accounts.

## Features

- **Online accounts** - Login with your Microsoft account
- **Offline accounts** - Play without an internet connection
- **No SSE 4.2 required** - Compatible with older CPUs (Qt 6.8)
- All PrismLauncher features preserved
